# MBOA Design Decisions (rulings from the user)

These rulings supplement `docs/GDD.md`. The user should fold them into the GDD text; until then this file wins
where it differs from the GDD. Dated entries, newest last.

## 2026-11-01
- **Tournaments are not fully optional.** The player must compete in tournaments to move the story forward. (The GDD says each seasonal tournament is optional; read that as: seasons that are not story gates can be skipped.) Which tournaments are story gates is not yet decided.
- **Habitats.** The player can build the base version of every biome habitat given the required materials. Winning tournaments unlocks habitat upgrades and may unlock new areas to explore.
- **Starting biome.** The farm starts with the first monster's biome habitat already built.
- **Pass-out penalty.** The player loses 10% of what they carry at the time. (Money confirmed by the GDD; whether carried items are included is to be confirmed.) The fixed bonding drop for monsters with the player is still undecided.
- **Clock.** Wake at 6:00 AM, 30 days per season, 60 real seconds per in-game hour.
- **Family grid.** The diagonal cells (same family) produce the same monster, since both parents are the same family: the Pedigree parent's species.
- **Stat letters for a 1-20 stat.** D 1-4, C 5-9, B 10-14, A 15-17, S 18-20. (Bands for stats with a different range, such as 1-25, are not defined yet.)
- **GDD source.** The PDF (`docs/GDD.pdf`) is the original and includes the villager table, which the markdown version dropped. The family crossing grid is empty in both.
